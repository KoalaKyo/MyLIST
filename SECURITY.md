# Security Policy

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version, reproduction steps, potential impact, and any suggested mitigation.

Security reports will be reviewed as time permits. No response-time or support guarantee is provided.

## Supported versions

Security fixes are applied to the latest published MyLIST version. Older versions may no longer receive updates.
