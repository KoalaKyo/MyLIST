# MyLIST documentation

This directory contains public English documentation for the MyLIST repository.

- prototype-interaction-map.md records the original desktop interaction prototype.
- The application-bundled MCP and Skill connection guide is located under app/windows-client/src-tauri/resources/docs.
- Release installers, source snapshots, checksums, and build metadata are published through GitHub Releases.

Internal product requirements, acceptance notes, and working review files are not part of the public repository.
