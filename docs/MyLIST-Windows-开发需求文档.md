# MyLIST Windows 客户端开发需求文档

> 文档版本：V1.0  
> 状态：开发基线  
> 最后更新：2026-08-21  
> 视觉真源：`E:\Codex\Todo_List\app\prototype`（当前 HTML 原型）

## 1. 产品与范围

MyLIST 是仅面向 Windows 的单用户、本地优先待办事项桌面小组件。它默认显示在桌面层，不遮挡普通应用；用户可切换置顶，并以低干扰方式管理待办、已完成事项、分类、截止时间、倒计时与逾期。

首发支持 Windows 10 22H2 与当前受支持的 Windows 11 x64 版本，以每用户安装包发布，不要求管理员权限。首发不包含账号、网络同步、协作、重复任务、子任务、附件、富文本、日历、第三方集成或 Android 安装包。

Android 为后续产品方向：复用 React 视图结构、领域模型、SQLite 迁移、导入导出格式、设计令牌和测试用例；桌面层、托盘、无边框窗口等 Windows 专有能力必须隔离在平台适配层。

## 2. 技术架构

### 2.1 技术选型

| 层级 | 技术 | 职责 |
|---|---|---|
| 桌面运行时 | Tauri 2 | 窗口、托盘、命令桥接、能力权限、安装打包 |
| 前端 | React + TypeScript | 页面、组件、可访问性、交互状态、Portal 浮层 |
| 前端状态 | 轻量 Store（Zustand 或等价方案） | 只保存 UI 状态、查询缓存和调用状态；不直接写文件或数据库 |
| 领域与系统层 | Rust | 任务规则、导入合并、加密、Windows 集成 |
| 数据库 | SQLite | 业务实体、版本信息、设备设置、导入快照与迁移 |
| Windows 集成 | Rust + Win32 API / Tauri 官方插件 | 桌面层、托盘、单实例、开机启动、顶部自动收起、显示器与 DPI |

前端只能经由受控 Tauri command 调用应用服务；不得直接使用任意文件系统、Shell、网络或数据库 API。所有 command 按最小权限声明，传入参数须在 Rust 边界再次校验。

### 2.2 模块边界

```text
React UI / Design System
        ↓ typed IPC
Application Services (Rust)
 ├─ Task / Category / Reminder use cases
 ├─ Import / Export / Merge use cases
 ├─ Window / Tray / Notification orchestration
        ↓
Repositories + SQLite transaction
        ↓
Windows adapters / Crypto / File system
```

- UI：渲染数据、收集操作、显示进度与错误；不实现合并规则。
- Application Services：所有业务写入的唯一入口；一个用户操作对应一个可回滚用例。
- Repositories：只负责查询和持久化，不决定业务规则。
- Windows adapters：以接口注入，供 Windows 集成测试替换为模拟实现。
- 未来 Android：替换窗口、托盘和文件选择器 adapter，保留领域层、数据模型、导入导出协议与 React 组件。

### 2.3 工程建议

```text
src/                 React 页面、组件、design tokens、IPC client
src-tauri/src/
  domain/            实体、校验、排序、版本比较
  application/       用例服务
  infrastructure/    SQLite、文件、加密、日志
  platform/windows/  WorkerW、托盘、窗口、顶部自动收起、Explorer 监听
  commands/          白名单 IPC command
tests/               Rust 单元/集成测试与前端组件测试
```

## 3. 视觉设计系统

### 3.1 基础尺寸与布局

- 默认窗口：360 × 520 DIP；最小窗口：320 × 360 DIP。
- 主标题栏高度：60 DIP；最小尺寸时可压缩至 48 DIP。
- 页签区域高度：44 DIP；灰色页签容器距标题栏和首条内容均为 8 DIP。
- 标题栏、页签容器、任务行外框、底部工具栏及普通页面内有外框模块的左右边距：8 DIP。
- 设置常规页无外框的内容区域左右边距：16 DIP。
- 底部栏高度：42 DIP；小尺寸时 38 DIP。中心添加按钮为 48 DIP 圆形，覆盖底栏上边缘。
- 使用 `Segoe UI Variable Text`，回退 `Segoe UI`、`Microsoft YaHei UI`。页面标题 18px，区块标题 14px，标准正文/菜单 13px，辅助文字 11px；同类控件不得自行增减字号。
- 所有图标使用 Microsoft Fluent UI System Icons，不使用 Emoji、自绘 SVG 或字符图标替代。

### 3.2 主题令牌

所有颜色、圆角、间距、阴影和交互状态必须通过设计令牌使用，禁止页面局部硬编码近似色。

| 语义 | 浅色模式 | 深色模式 |
|---|---|---|
| 窗口主背景 | 不透明近白蓝灰 | 不透明蓝黑 `#070B12` |
| 标题/底部/浅灰区域 | 统一浅灰蓝表面 | 比主背景仅略亮的冷黑蓝 |
| 悬停表面 | 标准浅灰区域 | 冷黑蓝悬停层 |
| 选中页签 | 白色，不描边 | 主背景色，不描边 |
| 主文字 | 深蓝黑 | 柔和浅灰蓝 |
| 次级文字/图标 | 蓝灰 | 中灰蓝 |
| 确认色 | 黑色 | 高饱和冷蓝 |
| 危险色 | 高饱和红 | 清晰但不荧光的红 |

- 深色模式禁止白色按钮、白色选中页签、浅色亚克力高光或意外透明面板；仅模态遮罩允许透明度。
- 所有弹出菜单默认采用白色背景（浅色模式）或深色面板背景（深色模式），与页面正文使用相同标准正文字号。
- 浅色的确认按钮为黑色；深色的确认按钮为蓝色。两种模式都必须有正常、悬停、按下、禁用、键盘聚焦状态。
- 白色选中页签在浅色模式按下仍保持白色，不得变成灰色；深色选中页签不得出现描边。

### 3.3 分类色

调色板固定为 3 行 × 8 列，共 24 个颜色槽；不显示颜色名称。第一行是高明度色，第二行是默认分类使用的中明度高饱和色，第三行是低明度色。分类颜色仅随分类实体变化，任务不提供单独颜色覆盖。

| 行 | 色值（按列） |
|---|---|
| 亮色 | `#D6E5FF`、`#D6F1FF`、`#D3F3E2`、`#FFDCDB`、`#FFECDB`、`#FFF5CC`、`#FBDBFF`、`#FFDBEA` |
| 中色 | `#8CB9FF`、`#7DD8FF`、`#77D6AC`、`#FF9390`、`#FFB774`、`#FFE36A`、`#D294F4`、`#FF93C6` |
| 暗色 | `#1A4FBC`、`#007DBB`、`#2E7D52`、`#A9282A`、`#B95612`、`#B58E00`、`#6E219E`、`#A72E6E` |

初始分类及对应中明度色：个人 `#FF93C6`、团队 `#D294F4`、工作 `#8CB9FF`、生活 `#77D6AC`、出行 `#FFB774`、财务 `#FFE36A`、学习 `#7DD8FF`、其他 `#FF93C6`。

分类圆点采用统一组件：外层 1px 灰色圆边，中心为更大的实心分类色圆；不得使用灰色内阴影。深色模式只调整显示层的对比度，不修改数据库内颜色值。

## 4. 页面与交互需求

### 4.1 主界面

- 标题居中显示 `MyLIST`；左上为图钉，右上为关闭。两者均距边缘 8 DIP。
- 图钉默认显示斜放图标；置顶后显示竖直、固定在线上的图钉图标，不改变按钮底色。悬停时使用标准小按钮悬停表面。
- 关闭按钮和删除按钮悬停时采用图钉一致的浅灰背景，图标保持危险红色；点击关闭只隐藏到托盘。
- 待办/已完成使用一个灰色大圆角分段控件。选中页签为小圆角矩形，数字在前、文字在后；选中数字为确认色圆底反白字，未选中数字为略深于容器的浅灰圆底。
- 待办排序：逾期优先、随后按最近截止时间、无截止时间最后；同键时按更新时间倒序、UUID 字典序稳定排序。已完成按完成时间倒序。
- 列表行单行展示：左侧状态/分类圆点、标题、右侧截止时间或倒计时。标题不可换行，空间不足显示省略号。
- 点击任务进入查看事项页面；右下中心添加按钮进入添加事项页面；左下设置按钮进入设置。
- 超长标题在被截断时，悬停显示位于窗口外的完整文本 Tooltip；未截断时不显示 Tooltip。

### 4.2 任务行、完成与删除

- 非悬停状态：左侧展示分类圆点；已完成和待办均一致。
- 待办悬停：分类圆点变为黑色空心完成圆圈；已完成悬停：分类圆点变为黑色实心白勾恢复按钮。
- 任务行悬停背景使用标题栏/底栏同一标准浅灰表面。悬停显示右侧操作时，隐藏提醒与时间文本。
- 待办右侧显示单个菜单圆按钮；菜单仅包含编辑、删除。点击页面其他位置必须关闭菜单；关闭后再次悬停不得自动重新打开，必须再次点击菜单按钮。
- 已完成右侧显示单个圆形删除按钮。菜单与删除确认浮层必须高于列表、提醒和其他行。
- 完成、恢复、删除均为两段确认：首次点击展开，第二次点击执行。展开或收起期间持续 300ms，并禁用重复点击；点击其他位置收起所有确认按钮。
- 完成/恢复左侧按钮：从与任务色环同尺寸的 20 DIP 圆形开始，展开为同高度胶囊；悬停最大 28 DIP。展开后只显示文字“已完成”或“移入待办”，不显示图标；文字左右内边距相等，参照删除按钮文字右侧留白。展开、收起时标题同步向右位移并线性压缩，均为 300ms。
- 已完成删除按钮：默认 28 DIP 圆形，首次点击后保持右侧锚点不动，向左展开为红色“删除”胶囊。展开、收起均为 300ms，文字与图标留白对称；正常、悬停、按下均为红底白字，仅红色深浅变化。
- **已完成删除确认展开时，任务标题的右边界必须同步向左收缩，使用相同 300ms 缓动。** 保留完成时间，不得覆盖它；标题不足空间时省略并可触发完整标题 Tooltip。收起后标题宽度同步恢复。
- 左侧完成/恢复胶囊与右侧菜单/删除确认不得同时处于展开状态，但两个操作入口在未展开时都保持可见。
- 删除后立即从界面和本地数据库永久移除；不提供回收站或跨设备删除传播。

### 4.3 添加、编辑与查看事项

- 添加、编辑、查看页标题栏与主界面高度、背景和居中标题完全一致；左上仅显示返回按钮，不显示右上关闭。
- 标题必填，去除首尾空格后 1–200 字符；备注为纯文本，最多 2,000 字符。
- 类型为必选分类；任务颜色由分类自动显示，不允许在任务表单选择颜色。
- 截止时间精确到分钟，允许保存过去时间并立即显示“已逾期”；打开日期时间浮层但未选时间时默认选中 18:00。
- 不提供任务提醒字段、提醒设置、Windows 通知或后台调度；截止时间仅用于列表时间、倒计时与逾期计算。
- 查看页字段只读，使用标准浅灰输入表面，不显示输入焦点描边；底部提供白色“编辑”和确认色“返回”。
- 查看页标题右侧提供标准圆形复制按钮；备注非空时在备注右侧提供相同复制按钮，复制时完整保留原始换行。备注为空时显示为空且不显示复制按钮。待办事项三点菜单提供编辑、复制、删除；复制内容为标题，若备注非空则追加一个换行和备注。已完成事项不增加菜单复制项。
- 添加、编辑底部提供取消/返回与确认操作，确认按钮文案为“保存事项”。
- 除 `input` 与 `textarea` 外，应用页面、标题栏、任务标题、标签、说明文字和只读字段禁止通过双击或连续点击选择文本；输入控件保留正常光标、文本选择和编辑。

### 4.4 日期、时间、菜单与浮层

- 所有浮层通过顶层 Portal 渲染，固定在窗口裁切层之外；必须根据可用屏幕空间翻转或偏移，不能触发页面滚动，也不能在最小窗口中被裁切。
- 日期时间浮层由带圆角边框的日历面板和时间面板组成。日历为月份导航、周标题、日期网格、清除、今天；时间面板为“时”“分”两列。
- 时间列显示多行相邻值，选中值为黑色/深色确认表面，上下值为灰色；支持滚轮滚动和顶部/底部小扁按钮。其垂直基线与日历月份、星期、日期行、底部操作分别对齐。
- 下拉菜单与任务菜单使用相同圆角、边框、行高、标准字号和主题令牌；选中项使用确认表面，未选中项悬停使用标准浅灰表面。

### 4.5 设置

- 设置页左上返回，标题“设置”居中；常规、分类、数据使用与首页相同的分段控件。修改立即保存，无底部保存/取消。
- 常规：外观使用明亮/黑暗双选图标分段控件（太阳/月亮），外观控件高度为 32 DIP，并沿用顶部页签的选中、悬停及深浅色规范；另提供随 Windows 启动开关。关闭状态开关比普通浅灰略浅，滑块采用当前主题主背景色。
- 常规提供语言下拉框。支持简体中文、英语、德语、法语、意大利语、西班牙语、日语与繁体中文；语言选择即时保存为本机设备设置，不参与导入导出。所有产品控制的可见文案、菜单、Toast、弹窗、无障碍标签与日期格式必须来自对应语言包；任务、备注及用户创建分类名称保持用户原始文本。
- 分类：显示分类色环、名称、编辑和删除按钮；底部有“添加分类”。添加后创建名称为“新分类”的分类，并分配尚未使用的颜色；无可用颜色时按调色板顺序循环分配。
- 编辑分类时，名称成为输入框，点击颜色环打开 24 色浮层，右侧操作变为“保存”。类型名不能为空，去除首尾空格后最长 20 字符，忽略大小写不得重复。
- 删除被引用分类时显示关联任务数量和目标分类选择器；确认后原子迁移。无引用分类可直接删除。
- 数据：导出、合并导入、覆盖恢复。导入前显示来源设备、导出时间、任务/分类/颜色数以及预计新增、更新、保留、删除、跳过、引用修复数。

## 5. Windows 系统能力

### 5.1 窗口与桌面层

- 无边框窗口支持拖动、右下角缩放；主界面显示 6 点等腰直角三角形拖拽提示，直角在右下角，设置页仍支持该热区但不显示点阵。
- 保存尺寸、位置、显示器标识和层级模式。显示器移除、分辨率变化或 DPI 变化后，修正至主显示器可见工作区。
- 桌面嵌入模式通过 Windows 桌面层 adapter 绑定 Explorer WorkerW/等价桌面宿主，确保位于普通应用之后；需完成独立技术验证。
- Explorer 重启后检测 shell 重新就绪并重新绑定。绑定失败时降级为非置顶普通窗口，保留状态并以退避策略自动重试，向用户显示一次可理解的提示。
- 置顶模式仅置于普通窗口之上，必须服从 UAC、锁屏和安全桌面。

### 5.2 托盘、单实例、生命周期与顶部自动收起

- 进程运行即注册托盘图标。标题栏关闭、Alt+F4 和系统关闭事件默认执行“隐藏窗口”，不退出应用。
- 主窗口必须禁用最大化：标题栏双击、拖至显示器顶端和系统最大化命令均不得进入最大化状态；窗口仍保留用户主动缩放能力，以免与顶部自动收起行为冲突。
- 托盘菜单含：普通/置顶模式时的“显示主界面”、桌面模式时的“显示桌面”、分隔线、三种互斥窗口模式、分隔线与“退出”。切换普通/置顶时若窗口隐藏，先恢复并聚焦，再执行切换。
- 双击托盘图标恢复当前模式下的窗口。退出菜单是唯一常规退出路径：提交数据库队列、移除托盘图标后退出。
- 使用单实例锁；第二次启动把参数转发至现有实例，现有实例恢复并聚焦窗口。
- 开机启动默认开启；使用 Tauri 官方自动启动插件注册当前 Windows 用户启动项，无需管理员权限。设置页开关修改后立即注册或移除，失败时不改变持久化值并显示简短错误提示；登录后直接显示主界面。
- 仅普通与置顶模式支持顶部自动收起：用户完成拖动后，窗口顶部贴到任意显示器顶部即以 300ms 收起，窗口向上移出屏幕，仅留 1 DIP 的标题栏背景色边缘；桌面模式不参与。
- 收起时以当前显示器 DPI 将 8 DIP 换算为鼠标热区；鼠标进入该显示器顶部、窗口水平范围内的热区自动展开，离开完整窗口再次收起。拖离顶部取消自动收起状态；切换到普通或置顶模式时，若完整窗口仍贴顶，必须重新判定并再次收起；桌面模式不参与自动收起。隐藏到托盘、托盘恢复、重复启动唤醒和退出均安全终止动画并恢复完整窗口。

## 6. 数据模型与导入导出

### 6.1 实体

| 实体 | 必要字段 |
|---|---|
| Task | `id`、`title`、`note`、`categoryId`、`status`、`dueAt`、`completedAt`、`createdAt`、`updatedAt`、`revision`、`updatedByDeviceId` |
| Category | `id`、`name`、`defaultKey`、`nameOverride`、`paletteColorId`、`sortOrder`、生命周期与版本字段 |
| PaletteColor | `id`、`hexValue`、`sortOrder`、生命周期与版本字段 |
| DeviceSettings | `deviceId`、主题、窗口位置/尺寸/显示器、层级、启动项、最近页签 |
| ImportSnapshot | `id`、创建时间、来源文件名、加密前的本机业务快照位置、校验信息 |

任务、分类、调色板均使用永久 UUID；完成、恢复、分类迁移、删除和颜色变化都必须递增 `revision`、刷新 `updatedAt`、记录 `updatedByDeviceId`。所有时间按 UTC ISO-8601 保存并以本地时区展示。八个默认分类额外使用稳定 `defaultKey`（`personal`、`team`、`work`、`life`、`travel`、`finance`、`study`、`other`）；界面按语言包显示名称，`nameOverride` 仅用于用户主动改名。

### 6.2 导出格式

明文文件为 UTF-8 `.dtodo.json`；加密文件为 `.dtodo`。两种格式解密/读取后的逻辑载荷一致：

```json
{
  "schemaVersion": 1,
  "exportId": "UUID",
  "exportedAt": "UTC ISO-8601",
  "sourceDeviceId": "UUID",
  "tasks": [],
  "categories": [],
  "paletteColors": []
}
```

- 导出完整有效业务数据，包括任务、分类和调色板；不导出 DeviceSettings，也不包含删除记录。
- 加密导出默认推荐，密码为 6–32 个 Unicode 字符，须二次输入确认。使用 Argon2id 派生密钥和 AES-256-GCM 认证加密；盐、随机数、算法参数可位于文件头，密码不得出现于文件、数据库或日志。
- 使用临时文件和原子替换写出文件；失败时不能留下看似成功的损坏文件。

### 6.3 导入与合并

- 默认“合并导入”：同 UUID 先比较 `updatedAt`，再比较 `revision`；仍相同时若内容哈希相同则跳过，否则以 `updatedByDeviceId` 字典序确定胜者并记录确定性冲突。
- 任务 UUID 不同即使标题、备注均相同也不得合并。导入仅新增或更新，绝不删除已有任务或分类；因此导入旧备份可能重新带回曾在本机手动删除的记录，确认页必须明确说明。
- 分类匹配规则必须由预检与真实导入共用：带 `defaultKey` 的默认分类优先按 `defaultKey` 匹配，不依赖语言显示名称或 UUID；普通分类优先按 UUID，再以名称为兼容兜底。名称相同但颜色不同，以导入文件颜色覆盖本地颜色。默认分类的 `nameOverride` 按 `updatedAt`、`revision`、`updatedByDeviceId` 合并。
- “还原默认分类”遇到已改名默认分类时，必须在同一事务中创建同名同色普通分类、迁移其事项、清除原默认分类的 `nameOverride` 并恢复其标准中明度色；原默认 UUID 与 `defaultKey` 不变。
- 导入顺序：校验 → 预览 → 创建快照 → 单事务导入调色板 → 分类 → 任务 → 修复引用 → 提交 → 显示汇总。
- 文件损坏、认证失败、密码错误、格式/UUID 错误、版本过新、快照失败或写入失败时，禁止修改业务数据。
- 覆盖恢复为高级入口，必须先完成文件/密码预检再二次确认；执行前创建本机快照，单一 SQLite 事务中替换任务、分类和调色板；本机 DeviceSettings 与导入快照记录保持不变。

## 7. 安全、隐私、兼容性与可访问性

- 核心功能完全离线；无遥测、分析 SDK、后台网络请求或账号体系。任何未来联网能力必须单独评审并默认关闭。
- 日志不得记录任务标题、备注、密码、完整导出内容或稳定设备标识。密码仅在操作内存中短暂使用，完成后尽快清理。
- 数据变更使用 SQLite 事务；启动时检查未完成导入。数据库损坏时停止写入、保留原文件并引导用户使用快照或导出恢复。
- 安装包使用有效发布者证书签名；升级保留数据库及设备设置；卸载默认保留数据，删除数据必须二次确认。
- 支持 Windows 10 22H2 与 Windows 11 x64、100%–200% DPI、多显示器与系统深浅色切换。需要验证 WebView2 运行时缺失时的安装提示与离线安装策略。
- 所有控件提供可读名称、可见键盘焦点和完整 Tab 顺序；颜色不是唯一状态表达。键盘支持 Enter 提交、Escape 关闭菜单/浮层或取消确认、方向键操作分段页签与日期选择器。
