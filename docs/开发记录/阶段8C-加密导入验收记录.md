# 阶段 8C-2：加密导入验收记录

- 状态：已通过人工验收
- 日期：2026-08-25
- 范围：密码加密 `.dtodo` 文件的识别、解密预检与合并导入。

## 已完成

- 数据选择器同时支持明文 `.dtodo.json` 和加密 `.dtodo`。
- 识别到加密文件后先要求输入密码；密码限制为 6–32 个字符，不保存、不写入导出文件或日志。
- 使用 Argon2id 派生密钥与 AES-256-GCM 解密，并校验文件版本、KDF 参数、随机盐、随机 nonce 与认证标签。
- 密码错误、文件被篡改或格式损坏时不会创建快照、不会写入 SQLite，也不会清除已选文件，用户可直接重新输入密码。
- 解密成功后进入与明文完全相同的导入预检和确认合并流程；合并仍只新增或更新，不删除本地事项和分类。

## 自动验证

- `npm run build`：通过。
- `cargo test`：通过（15 项）；包含加密导出/解密回环、错误密码与密码长度边界测试。

## 人工验收

1. 先导出加密 `.dtodo` 文件，设置 6–32 个字符密码。
2. 设置 → 数据 → 导入，选择该 `.dtodo`；确认进入“加密文件”密码框。
3. 输入错误密码，确认只出现错误提示，原有任务与分类不发生变化；再次输入无需重新选文件。
4. 输入正确密码，确认出现“导入预检”，再确认导入结果符合新增/更新/保留统计。
5. 将 `.dtodo` 改坏一个字符后再导入，确认提示失败且本机数据不变。
