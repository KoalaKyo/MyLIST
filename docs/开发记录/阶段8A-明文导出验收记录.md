# 阶段 8A：明文导出验收记录

## 本模块范围

- 数据页提供 `.dtodo.json` 明文导出入口。
- 导出完整有效任务、分类与 24 色调色板。
- 导出包包含 `schemaVersion`、`exportId`、`exportedAtUtcMs` 与 `sourceDeviceId`。
- 设备设置不导出；任务和分类的删除记录不保留、不导出。

## 自动验证

- `npm run build`：通过。
- `cargo test`：13 项通过。
- 新增测试：导出仅包含有效业务数据、24 色调色板与八个默认分类，且 JSON 不包含删除标记或已删除任务内容。

## 人工验收

1. 打开设置 → 数据，点击“导出数据”。
2. 在保存对话框选择目录并保存 `.dtodo.json` 文件。
3. 用文本编辑器打开文件，确认含 `schemaVersion`、`palette`、`categories`、`tasks`。
4. 确认文件中没有 `deletedAtUtcMs` 字段；删除事项后重新导出，已删除事项不在文件中。
5. 确认主题、窗口模式和开机启动设置不在文件中。
