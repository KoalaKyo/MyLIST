# 阶段 8D：多语言基础验收记录

日期：2026-08-25  
状态：待人工验收

## 已完成

- 新增八个同层 locale 文件：`zh-CN.ts`、`en.ts`、`de.ts`、`fr.ts`、`it.ts`、`es.ts`、`ja.ts`、`zh-TW.ts`；非中文语言当前以简体中文基准作为回退内容。后续翻译仅需在目标语言文件中按键覆盖，不需要修改业务代码。
- 新增类型安全的前端翻译函数、语言包键集启动校验与 `Intl` 日期格式化入口。
- `device_settings` 新增 `locale`，默认 `zh-CN`，语言选择即时持久化且不参与导入导出。
- 设置 → 常规新增独立 Portal 语言下拉菜单；前端会在启动及语言切换后把同一语言包的托盘与文件选择器标签同步给 Rust，原生层不再自行维护各语言翻译。
- 已迁移主界面、设置主导航、数据页、表单、日期时间组件、任务菜单、查看事项、Toast 等高频可见文案到语言键。

## 人工验收步骤

1. 打开设置 → 常规，确认“语言”下拉框包含八种语言名称。
2. 逐个切换语言，确认当前阶段内容仍显示完整中文、界面不抖动或裁切。
3. 关闭并重新启动应用，确认最后选择的语言仍被保留。
4. 右键托盘图标，确认“显示主界面 / 显示桌面”、三种模式和“退出”菜单正常。
5. 在 350×530 DIP 与 150% DPI 下打开语言下拉菜单，确认菜单不会被裁切。

## 后续翻译边界

后续由独立翻译 Agent 每次处理一个语言文件的一小批键；每批必须保持键集一致、进行该语言视觉回归，并不得修改用户数据内容。
