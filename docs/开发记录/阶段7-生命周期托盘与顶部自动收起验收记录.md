# M07A / M07B Windows 生命周期、托盘与顶部自动收起验收记录

## 范围

- 已移除 Windows Toast、通知权限、任务提醒调度、错过补发与稍后提醒的首发需求。
- 已保留截止时间、倒计时和逾期显示；不再提供独立提醒字段或后台通知服务。
- 已接入普通模式与置顶模式的顶部自动收起：窗口拖至任意显示器顶部并停止移动后，300ms 向上收起，仅保留 1 DIP 标题栏色边缘。
- 已接入收起状态下的 8 DIP 顶部鼠标热区、自动展开、离开窗口自动再收起和拖离顶部自动退出该状态。
- 已接入托盘恢复、单实例唤醒、模式切换、关闭隐藏和主动退出前的完整窗口恢复，桌面模式明确不参与自动收起。
- 已禁用原生最大化样式与配置项；标题栏双击和拖至屏幕顶部不得触发最大化，避免干扰顶部自动收起。
- 已补齐模式切换后的收起联动：从桌面模式切回普通或置顶模式时，只要完整窗口仍贴顶，即重新走顶部判定与 300ms 收起；桌面模式始终排除。
- 已接入当前用户启动项：默认开启、设置页即时开关、登录后显示主界面；注册失败不会写入错误的持久化值。
- 已接入官方剪贴板能力：查看事项可分别复制标题与非空备注，待办三点菜单可复制“标题 + 换行 + 备注”；复制成功或失败均有 Toast。
- 已在应用壳禁止非输入区域文本选择；`input` 与 `textarea` 仍可正常选中、编辑。

## 人工验收

1. 在普通模式把窗口拖到主显示器顶部，松开后确认约 300ms 收起，仅留一条标题栏色边缘。
2. 将鼠标移入该边缘下方 8 DIP 区域，确认窗口约 300ms 自动展开；移出窗口确认再次收起。
3. 切换到置顶模式并重复步骤 1–2；切换到桌面模式确认不会自动收起。
4. 在收起状态下，分别通过托盘“显示主界面”、托盘双击、重复启动应用恢复窗口，确认不会遗留不可见窗口。
5. 在双显示器和 100%/150%/200% DPI 下重复顶部收起与恢复；再把窗口拖离顶部，确认不会继续自动收起。
6. 在收起状态从桌面模式切换至普通/置顶，确认重新收起；切换到桌面模式确认不收起。
7. 在设置-常规验证“随 Windows 启动”默认开启，切换开关后重启应用确认设置保持；登录启动场景确认显示主界面。
8. 验证标题栏、任务标题和设置文字无法被双击选中，输入框和文本域仍可选中文本。
9. 验证查看事项标题复制、带备注事项的备注复制、空备注不出现复制按钮；验证待办菜单复制结果为标题和备注之间一个换行。
10. 关闭主窗口至托盘、切换三种模式并选择“退出”，确认窗口状态和托盘菜单无错乱。
