# 阶段 9B：安全与运行可靠性验收记录

日期：2026-08-25  
阶段：9 / 发布加固  
模块：9B / 安全与运行可靠性

## 本次完成

- 启用 Tauri 内容安全策略（CSP）：仅允许应用自身资源、Tauri IPC、受控本地资源协议与必要的内联样式；不允许任意远程脚本、对象内容或表单提交。
- 移除未使用的 `opener` 依赖、Rust 插件初始化与能力权限，发布包不再携带外部打开能力。
- SQLite 初始化新增：外键约束、WAL、完整同步、`trusted_schema = OFF` 与 `secure_delete = ON`。
- 数据库在启动阶段无法验证或打开时，使用原生 Windows 错误提示说明“未修改任何数据”，且不向用户暴露底层 SQLite 错误、路径或不可信内容。
- 清理 Vite 默认页面标题与图标引用，发布 WebView 元信息统一为 MyLIST。

## 人工验收步骤

1. 运行 Debug EXE，确认主界面可正常加载，未出现空白或 CSP 错误。
2. 创建、编辑、查看与删除一条测试事项，确认原有业务流程无变化。
3. 打开设置并切换主题、语言，确认本地语言文件与托盘菜单仍可用。
4. 退出后重新打开，确认本地数据仍存在。

## 本模块不包含

- 数据库损坏后的图形化恢复/重建向导；当前策略是停止启动、明确提示且绝不静默改写数据。
- 代码签名、正式安装包、升级与卸载验证。
- 性能基准、无障碍完整审计、Windows 10/11 发布候选真实机回归。
