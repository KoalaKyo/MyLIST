状态：已通过人工验收

## 本次范围

- 新增 Windows 桌面模式：主窗口绑定 Explorer 的 WorkerW 桌面层，位于普通应用窗口之后。
- 托盘菜单改为三种互斥且带勾选的窗口模式：置顶模式、普通模式、桌面模式。
- 模式切换规则：桌面模式会取消置顶；置顶/普通模式会脱离桌面层。
- 绑定失败时返回错误并保留普通窗口能力；不影响托盘、单实例或关闭隐藏。
- 2026-08-21 修订：模式状态以 Rust 为唯一来源；界面通过原生事件同步，托盘三项勾选由同一状态回写，任何时刻仅允许一项选中。
- 2026-08-21 修订：桌面模式除绑定 WorkerW 外，同时切换为子窗口样式并置于 WorkerW 底层；绑定校验失败时恢复原始顶层样式。
- 2026-08-21 修订：针对本机 `FindWindowW` 无法直接取得 `Progman` 的 Explorer 实现，增加 `EnumWindows` 枚举兜底定位；从托盘进入桌面模式时不再执行窗口聚焦，避免破坏“始终位于普通窗口之后”的层级。
- 2026-08-21 修订：放弃将 Tauri 窗口作为 WorkerW 子窗口的实现。该方式在本机将窗口置于桌面图标下且回退不完整。改用桌面宿主所有者锚定，保留顶层窗口的正常输入、拖动与关闭能力，同时使其位于普通应用窗口之后。
- 2026-08-21 人工验证：桌面模式切换成功。
- 2026-08-21 人工验证：三种模式与托盘菜单同步正确；桌面模式保留正常标题栏控制按钮；关闭到托盘再恢复后，实际窗口层级仍保持桌面模式。

## 人工验收步骤

1. 右键 MyLIST 托盘图标，确认“置顶模式、普通模式、桌面模式”中恰好一项带勾。
2. 选择“桌面模式”，打开记事本或浏览器，确认 MyLIST 位于这些普通窗口之后；按 `Win + D` 显示桌面后应能看到它。
3. 再从托盘选择“置顶模式”，确认窗口恢复并显示在普通窗口上方；菜单勾选同步切换。
4. 选择“普通模式”，确认 MyLIST 可被普通窗口遮挡。
5. 分别从界面按钮和托盘菜单切换三种模式，确认另一处立即同步，且三项中始终只有一项带勾。
6. 在三种模式间反复切换，确认不会崩溃或丢失托盘图标。
7. 在桌面模式下关闭主窗口，确认其隐藏到托盘；双击托盘图标恢复后，再切换到普通模式。
8. 重启 Explorer（任务管理器中重启 Windows 资源管理器）后，确认应用仍可从托盘恢复；若桌面绑定失效，切回普通模式后应用仍可正常使用。

## 已知限制

- WorkerW 是 Explorer 的非公开实现细节，不同 Windows 版本、替代桌面外壳或 Explorer 异常状态可能导致绑定不可用。
- 本实现已做到绑定失败安全降级；Explorer 重启后的自动检测与重绑将在 0B 验收通过后追加为下一小步，以免和当前模式切换逻辑混合变更。
- 当前窗口仍是阶段 0 的能力验证界面，尚未接入正式无边框外观、数据或提醒功能。
